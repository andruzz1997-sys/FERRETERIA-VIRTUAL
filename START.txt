🚀 CÓMO EMPEZAR (3 OPCIONES FÁCILES)
===============================================

OPCIÓN 1: CORRER LOCALMENTE (MÁS FÁCIL) - 30 segundos
========================================================

1. Instalar dependencias con npm:
   cd "c:\Users\duvan\OneDrive\Documentos\PROYECTO FERREWEB"
   npm install

2. Iniciar el servidor:
   npm start

3. Abrir en navegador:
   http://localhost:3000

✅ ¡Hecho! Tu tienda está corriendo localmente.


OPCIÓN 2: CON PYTHON (SIN npm) - 15 segundos
=============================================

1. Abrir PowerShell en la carpeta del proyecto

2. Ejecutar:
   python -m http.server 8000

3. Abrir en navegador:
   http://localhost:8000

✅ ¡Funciona! (Nota: sin backend, solo frontend)


OPCIÓN 3: CON DOCKER - 1 minuto
===============================

1. Tener Docker instalado

2. Ejecutar:
   docker-compose up -d

3. Acceder:
   http://localhost:3000

✅ ¡La aplicación corre en contenedor!

🔐 INSTRUCCIONES DE DESPLIEGUE
===============================================

DESPLIEGUE EN HEROKU (Gratis por 12 meses):
=============================================
1. heroku login
2. heroku create mi-ferreweb
3. git push heroku main
4. heroku open
URL: https://mi-ferreweb.herokuapp.com

DESPLIEGUE EN GITHUB PAGES (Gratis):
====================================
1. Crear repositorio en GitHub
2. Subir archivos
3. Settings → Pages → Deploy from main
URL: https://tu-usuario.github.io/ferreweb

DESPLIEGUE EN VPS (Tu propio servidor):
=======================================
Ver archivo DEPLOYMENT.md para instrucciones detalladas
- Ubuntu/Debian con Node.js y Nginx
- PM2 para gestión de procesos
- SSL con Let's Encrypt
- Base de datos PostgreSQL (opcional)

DESPLIEGUE CON DOCKER:
=====================
1. docker-compose up -d
2. La app estará en http://localhost:3000

📱 CÓMO PERSONALIZAR
===============================================

CAMBIAR COLORES:
================
Editar css/styles.css:
--color-amarillo: #FFD700;      ← Cambiar color
--color-verde: #228B22;          ← Cambiar color

AGREGAR PRODUCTOS:
==================
Editar data/products.json y agregar:
{
  "id": 21,
  "name": "Tu Producto",
  "category": "Categoría",
  "price": 1000,
  "description": "Descripción",
  "stock": 50,
  "rating": 4.8,
  "emoji": "🔧"
}

CAMBIAR TEXTOS:
===============
Editar directamente en index.html:
- Nombre de tienda: "FerrreWeb"
- Descripción: "Tu Ferretería Online"
- Colores: Ver CSS

AGREGAR NUEVA PÁGINA:
====================
1. Crear nuevo .html
2. Importar CSS y JS
3. Linkear desde index.html
